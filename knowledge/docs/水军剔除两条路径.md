# 水军剔除两条路径（勿混用）

chat_bi 里水军（blacklist 用户）剔除存在两条实现路径，来源不同，同一分析内只用一条并在说明中注明：

## 路径一：活跃表打标字段（blacklist_tag）
- 用法：`WHERE blacklist_tag != 'is_water'`（MAU拆解(rooc).sql 的 MAU/MRU/MOU 口径）。
- 来源：活跃明细表自身的 blacklist_tag 列。

## 路径二：黑名单表左连（dws_user_blacklist）
- 用法：`LEFT JOIN roo_analyst.dws_user_blacklist`，`tag='is_water'` 命中即剔除（月持续活跃(rooc).sql 的 MOU 持续活跃口径）。
- 来源：独立黑名单表，按账号剔除。

## 注意
- 两条路径的名单更新节奏/范围可能不同，混用会造成前后口径不一致。
- 引用时注明「按 blacklist_tag 剔除」或「按 dws_user_blacklist 左连剔除」。

## 来源
- MAU拆解(rooc).sql、月持续活跃(rooc).sql
