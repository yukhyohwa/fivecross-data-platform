# 小新繁体活动时间表与规则（D1–D35）

本目录是**时间表与逻辑覆盖项目**，不承担活动比较报表的收入/人数刷新。数据引用时先读本表，再按当次需求重新取数；不因引用规则自动更新 Excel/PPT。

## 时间判定规则

- 活动表来源：`inputs/蠟筆小新-繁體版開服活動整理_20261031.xlsx`，工作表 `活動排期_obt調整版`。
- 活动表当前记录到开服 **D35**；逐日明细见 `reference/activity_schedule_day1_35.csv`。
- 未标注“需要配指定日期”的活动：按各服开服日龄；D1为首位有效 `new_role` 的自然日，午夜切换。
- 开心福引机的 `occurrence_no` 表示该产品系列第几次投放；同一系列后续复刻新增2、3等编号，不覆盖历史期次。活动名称按 `活动_道具` 记录，不使用仅有期号的 `giftbox_1` 或“开心福引机1”作为展示名称。
- `parent_key` 用于标识父子活动：垂钓、盲盒、露营手册、露营自选礼包归属野外露营；大富翁自选礼包和时装礼包归属人生大富翁。
- 标注“需要配指定日期”的活动使用自然日；其他活动按开服日龄。
- 野外露营：用户确认按自然日，活动表J23:J29显示 **2026-11-04–2026-11-10**；精确开关时刻待确认。
