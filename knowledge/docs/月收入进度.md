# 月收入进度算法

## 汇总表
public_analyst.rpt_allgame_kpi，列：stat_date、game_code、new_users、paying_users、total_revenue、active_users、monthly_revenue_to_date、last_month_revenue_to_same_day、monthly_progress_ratio。

## 月收入进度算法
- monthly_progress_ratio = round(monthly_revenue / last_month_revenue × 100, 2)：本月截至目标日月流水 ÷ 上月截至同日流水，保留两位小数。
- 上月截止日 = 上月末日与目标日的较小者（last_month_end.replace(day=min(target_date.day, last_month_end.day))）——分母是"上月截至同日"，不是上月整月。

## 注意事项
- 读该表要 coerce_numeric=True：DECIMAL 列读出是 Decimal 对象，直接做乘法会 TypeError；开关只转确实装着 Decimal 的列（通用的 pd.to_numeric 会把数字形态的字符串列一起转掉，方向反而错）。
- 进度超 100% 表示本月已超上月同期，不是数据错误；月初几天分母小、进度波动大属正常。
