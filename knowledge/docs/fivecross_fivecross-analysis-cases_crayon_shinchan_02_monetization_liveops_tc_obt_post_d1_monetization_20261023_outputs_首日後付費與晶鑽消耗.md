## 每日趨勢的三條路徑

每日趨勢分別展示現金購買商品、購買晶鑽、晶鑽消耗，全部以台幣表示。前兩者相加才是當日現金收入；現金商品加晶鑽消耗，再排除晶鑽購買儲值／換幣商品，才是最終商品活動消費額。首日後此類換幣排除 NT$51,673.00，單列核對。三條路徑不能全部相加。Excel 保留全部玩家、創角首日後、10月14日首批玩家三種範圍，避免後進玩家的首日支出混淆續購。

## 同批活躍玩家的最終消費變化

固定同一批7,300名10月14日創角，且10月15、16、19、20日均活躍的玩家。前期10月15–16日，後期10月19–20日。現金商品與晶鑽最終消費合併，排除儲值／換幣商品及內部用戶。

## 經營結論

收入支撐仍集中於首日已付費及累積中高 R 玩家，但商品需求必須把晶鑽支付納入。免廣告、新人禮、基金等一次性價值購買，與副本補給、限時活動等可持續投入，應用合併消費額、跨日續購人數共同判讀，而不是只比較充值 SKU。

## 需求與頁簽對照

| 分析問題 | 對應頁簽 | 重點讀法 |
| --- | --- | --- |
| 首日後付費情況及收入由誰支撐 | 收入分層 | 首日已付費／未付費、累積分R及首日分R的後續收入 |
| 這些玩家買了哪些商品或活動 | 商品與活動消費 | 按分R篩選，依合計消費排序；分開看現金與晶鑽支付 |
| 中小R首日後還會買哪些商品 | 首日後購買／商品與活動消費 | 創角翌日起所有購買，買一次也算；同商品跨日復購只作補充 |
| 中小R消費的價格區間 | 價格區間 | 按分R篩選，價格帶合併現金訂單與晶鑽扣款 |
| 收入下滑出現在哪個支付路徑及日期 | 每日趨勢 | 現金商品、購買晶鑽、晶鑽消耗分開比較；不是三者相加 |

目前可以回答收入來源與購買／續購偏好，但尚不能把這些描述直接當成「排除流失後收入下滑的主要原因」。仍需以相同玩家群、相同生命週期比較活躍者付費率、付費者客單與購買頻率，並檢查一次性禮包需求消退、活動節奏，以及晶鑽餘額是否替代新儲值。期末累積分R收入集中只是結構，不是下降的因果解釋。

首日後晶鑽消耗約 15.0% 尚不能唯一歸因，保留在商品與價格合計的未歸因項，不強行指派活動。晶鑽可能來自較早儲值、返利或贈送，所以最終消費需求不等於當天新收入。付費分層是截至觀察期末的描述，較晚創角玩家可觀察的續購天數也較少。
