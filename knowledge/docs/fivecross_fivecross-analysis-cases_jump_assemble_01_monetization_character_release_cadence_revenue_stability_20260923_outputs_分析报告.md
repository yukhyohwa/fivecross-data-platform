## 可执行建议

### 优先：错峰而非盲目加速
保持S卡总量，测试将可拆分的A级/复刻/资源养成活动移至空档周；先验证目标用户、奖励和角色供给是否允许拆分。
- 衡量：主指标：固定完整28天有效收入/每活跃账号人天收入；次指标：周收入波动、低谷周收入。
- 护栏：护栏：留存、付费人数、首发7日收入、三觉完成率；避免只把下周消费提前。

### 优先：修复香吉士进池漏斗
结合既有案例核查入口曝光→参与→持有→三觉；不能用缩短上新周期掩盖进池不足。
- 衡量：按同一首五日比较参与率；分母用窗口去重活跃账号。
- 护栏：三觉完成=英雄胚子1份+觉醒消耗3份；持有覆盖与持有人内三觉率分开。

### 复刻承担补位需检验
9/2复刻确有开售但不能视为新S首发等价冲击；以持有/觉醒缺口分群评估潜在购买者。
- 衡量：同类复刻D1-D5、净新增付费/参与人数和28天总收入。
- 护栏：不直接将五条复刻和新角色全游戏收入差判为角色偏好。

### 实验设计
优先服务器/地区可比随机组；不可分组时采用多轮相似阶段交替排期，并匹配活跃规模和同期促销。
- 衡量：至少覆盖多个完整轮次；预先规定主指标及检测标准。
- 护栏：同时控制首充重置、月卡/BP、版本更新、流量、角色人气与强度。

## 方法、证据边界与来源

- **分析范围**：Jump TC / Global ThinkingData event23；2026-06-24—2026-09-20；非 CN event4。
- **业务问题**：非角色投放周收入是否低迷？应调整开售节奏还是改善现有角色承接？
- **收入**：全游戏 PURCHASE，排除 SANDBOX_RECEIPT；wallet event16 按 purchaseid 扣免费额后换算 USD；不是角色归因收入。
- **账号**：COALESCE(fc_sdk_common.lcx_id, sdkcommon.lcx_id, #account_id)；LOGIN_SUCCESS 日去重。
- **排除**：internal_users / is_water / is_water_mod / suspicious_ip；按查询时群组排除。
- **比率**：日付费账号/日登录账号；非严格登录 cohort 付费转化率，付费事件未与当日登录账号求交集。
- **周聚合**：收入求和；日均活跃=活跃账号人天/天数；付费比=付费账号人天/活跃账号人天；ARPPU=收入/付费账号人天。不是周去重 WAU、周去重付费人数或周 ARPPU。
- **收入恒等式**：完整周收入=7×日均活跃×付费账号人天比×每付费账号人天收入；对数分解仅为算术分解，不是因果贡献。
- **定义**：无新开售事件周≠无角色在售；包含新卡、复刻和独立活动的开始日期；活动结束日按周报日历含端点，非服务器关服时刻。
- **机制差异**：8/05 item62 角色未确认；8/19 item57、8/26 item67 独立活动不同于 gacha；不把其资源次数与抽数混加。
- **同日投放**：8/26 白哉+善逸作为同一日期事件组；五日全游戏收入仅计一次，不拆给两个角色。
- **与周报差异**：周报 daily_kpi 使用 fixed_deviceid、NUU/LOGIN/PURCHASE 活跃、较少黑名单且未扣钱包免费额；本case为账号有效付费口径，不能期待与周报金额直接相等。
- **样本限制**：完整自然周12个，无新开售事件完整周仅1个；不使用简单分组均值推断最优周期。首周不完整，单列。
- **未审计风险**：SQL沿用缺失汇率=1；PURCHASE收入未做订单级去重；wallet仅取窗口内。当前未另行量化这三项影响，不称为财务净收入。
- **历史案例**：香吉士D1-D5案例README指出进池规模不足、已进池者深度不弱；仅作独立既有研究参考，不与本case用户范围强行拼接。
- **同期首充双倍**：2026-09-09与香吉士同日上线每玩家、每躍之星档位活动后首次购买双倍，机制长期持续；9/14—9/20仍处机制生效期。不能把两周视为有促销/无促销对照。来源：../../02_liveops_payments/jump_star_first_topup_double_20260909/README.md。
- **双倍证据界线**：既有双倍案例首五日核心8个SKU收入占比70.6%，指这些SKU全部有效购买，不是首次双倍订单占比、已核实领双倍奖励收入或净增收入；本次未重算该比例。
- **双倍待验证机制**：首周优惠机会使用、充值前置与额外货币存量可能影响次周充值，但当前未验证；需拆9/9—9/13与9/14—9/20合资格SKU首次/重复购买、剩余机会、资源收入消耗余额。
- **结论边界**：仅能确认无新开售事件周收入较低；首周与双倍上线重叠，次周仍在双倍期，缺少独立对照，不能把差额单独归因于角色节奏，也不能证明缩短S卡周期提高收入。
