# 新老回流分层口径（三分层 vs 四分层并存）

同一批 KPI 模板里存在两套账号分层口径，按模板选择，不要混用：

## 三分层（每日KPI(rooc).sql 及周/月版本）
- 1-新账号：`a.date = reg_date`（注册当日）
- 2-老账号：`DATEDIFF(date, last_login_date) <= 7`，或 last_login_date 为空且注册日在 7 天内（OBT 前 7 天新服兜底）
- 3-回流账号：其余
- 用途：日/周/月粒度 KPI 的活跃、付费、ARPU 拆解。

## 四分层（DAU历史(rooc).sql）
- nuu / ouu / r2uu / r7uu：新用户、老用户、2 日回流、7 日回流（按回流间隔细分）。
- 用途：分日 DAU 历史序列的账号构成分析。

## 注意
- 两套并存是历史原因：回答「新/老/回流」构成时注明用的是哪套分层（三分层 or nuu/ouu/r2uu/r7uu 四分层）。
- 三分层里的「2-老账号」包含部分注册不足 7 天的账号，与四分层 nuu 的定义边界不同。
