# 繁体服历史角色首售7自然日备份

最终Excel：../outputs/final/灌篮繁体服_历史角色首周活动备份.xlsx

- 范围：繁体服 app23002013；历史传奇21位+殿堂3位；不声称普通/集训/进阶全部角色均覆盖。
- 首售口径：以专属正金额礼包订单的最早观测交易日为起点，包含当日连续7个自然日。SKU发现扫描2023-01-01至2026-05-27（已知维度SKU另查2020起），TA查2026-05-28至10-28。不是币首次免费发放日；运营开售公告尚未逐一复核。
- ODPS：2023-2026历史角色：dm_platform.daily_lcx_user_purchase / g23002013.daily_game_log。
- TA：殿堂流川、传奇高野、殿堂宫城：ta.v_event_20，排除SANDBOX_RECEIPT，金额>0。
- 收入：仅角色专属SKU，按原币分组；ODPS使用交易实际月份首条CNY汇率，TA使用实际交易日期汇率。无同期全SKU收入冒充角色收入。
- 获得消耗：只使用明确道具ID映射。消耗为全部负资源变化，包含抽奖、出售等，按来源事件可区分。
- 同事件点券：只累计目标币正向获得的同一原始事件里负向付费点券/免费点券/钻石；汇总使用事件级去重，不是角色总支出/现金收入。
- 连锁归因：角色已证实连锁支出为chain_buy且同事件正向获得角色专属币的可证实部分；另保留整个7日窗口所有连锁及活动/链/礼包ID，但不能把同期全连锁都算该角色。
- 不重复相加：同事件点券与已证实连锁点券存在包含关系；币明细不同币行同事件成本可能重叠，金额总计请用事件级成本表。
- 未知：无结果或映射未核实用空白/未知，不造0；来源数据中实际0原样保留。人数为各天/币/事件/SKU分组去重，不应相加当作7日独立人数。
- 过滤：历史备份未额外剔除黑名单/水用户；ODPS沿用平台订单表正金额口径，不承诺全额现金回款。
- 标识：表内只含聚合指标和业务SKU/活动道具ID，无个体玩家身份信息。
