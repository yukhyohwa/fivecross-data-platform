- [ ] `daily_lcx_user_info` 的日期范围覆盖目标月、上月活跃判断和新增留存观察期。
- [ ] 用户 ID 在月度聚合前后均使用 `lcm_id` 去重。
- [ ] `New`、`Old_RegL2M`、`Old_OTH`、`Return` 在同一月互斥，人数之和等于 MAU。
- [ ] `Old_RegL2M` 的注册月份窗口与业务定义一致；修改“近两个月”时同步调整 README 口径。
- [ ] 所有收入均来自 `purchase`，ARPU 分母为对应用户分层人数。
- [ ] 新增 D1/D3/D7 留存的注册 cohort 与观察日期完整，未成熟 cohort 不进入对比结论。
- [ ] 国家字段 `country_name` 的缺失值、未知值和名称变化已单独检查。
- [ ] 国家维度总收入与月度总收入在相同日期、相同过滤条件下可合理对账。
- [ ] PDF 和 CSV 为历史快照；复跑时输出新文件，保留运行日期与 SQL 版本。
