# JUMP TC：日常收入下降与角色养成需求

本案例围绕一个经营问题展开：**排除新角色上线最初几天的波动后，日常收入为什么降了一个台阶？是玩家离开、养成目标减少，还是持续培养主要依靠已有资源，因而没有转化为新的充值？**

最终报告为66页运营分析：[JUMP_TC_八题分析_两周期消费Top10_20261109.pptx](outputs/eight_questions_20261023/JUMP_TC_八题分析_两周期消费Top10_20261109.pptx)。数据观察截至2026/11/5，最后一次展示调整为2026/11/9。本目录独立保存最终报告的生成代码、查询结果、配置快照和校验记录，不依赖原临时项目目录运行。

## 分析思路

先定位收入少在什么地方，再检验养成能否解释这部分减少。不能从“收入下降”直接跳到“角色养满”，也不能从“仍有培养”直接推出“应该有充值”。因此将问题拆成八章，每章都有业务问题、可检验证据和章节结论。

| 章节／业务问题 | 如何验证 | 结论的适用边界 |
|---|---|---|
| 1. 日常收入少在什么人、什么商品？ | 同时看现金收入、日均活跃、人均收入；结合角色和活动关键时间表，区分首发节点与其他日期；定位充值和购买类别的变化。 | 避免把活跃人数减少全部解释为付费需求减弱。 |
| 2. 少付费的人是否也减少养成？ | 固定账号比较两个完整周，按登录与等级／觉醒／天赋操作变化分为8个互斥组，核对各组现金变化；再按活跃天数校正。 | 行为组用于定位现金减少，组间占比不是独立原因贡献。 |
| 3. 收入减少人群的常用角色是否已养满？ | 持有、等级、天赋、觉醒分开衡量，A／S分开；再用近期上场最多的3名角色识别实际使用目标。 | 持有全部角色、常用角色养满、全部角色养满是不同概念；满养不等于没有新目标。 |
| 4. 获得角色后，培养参与和完成情况如何变化？ | 使用关键事件表解释角色取得机制；按取得渠道与时间比较取得后7日培养、14日完成。 | 使用完整观察窗，区分取得批次、活动阶段和渠道；不同人群的比例差异不能直接解释为活动的因果效果。 |
| 5. 持续培养由旧库存还是当期供给支持？ | 先盘点养成一个目标所需材料，再按历史卡池／活动重建期初储备、当期获得与实际消耗，计算旧库存可支持的上下界。 | 余额足够只能证明有能力支付资源成本；流水无法唯一识别先花旧库存还是新供给时，用边界而不强行归因。 |
| 6. 抽卡储备较多，是否就更少充值？ | 跃之星与限时阅览券换算可抽次数，按各周起点储备分档观察付费覆盖、客单；补充两周都可核验的同一批玩家。 | 各期分档总体不是同一批人；共同样本用于避免直接把人群更替当作行为变化。 |
| 7. 持续培养者少付，是付费人数减少还是客单下降？ | 在固定行为组内把现金变化拆为付费人数和付费者客单变化，核对总账。 | 这是账面分解；不能独立证明玩家意愿或商品吸引力的变化。 |
| 8. 少付费主要对应哪些商品与消耗去向？ | 现金侧合并跃之星充值，其他具体商品列Top14；消耗侧分别列两周各自的付费星消耗Top10。 | 现金和代币消耗分开计量，不相加；具体商品变化提供经营定位。 |

证据链按“收入变化 → 人群变化 → 养成目标 → 资源支持 → 付费人数／客单 → 商品去向”展开。库存是解释链条的一环，不能替代收入和购买行为本身。

## 最终报告的主要发现

- 固定老用户最新对照周现金收入为10,278.91美元，比前期减少53,351.75美元。后期无登录、停养、持续少养分别对应净减少额的36.2%、33.1%、34.4%，其他增长人群形成抵消，所以前三项可以超过100%。
- 8月至10月，固定老用户日均活跃和每活跃人日收入同时下降。收入变化不能只用活跃规模解释。
- 2,049名持续少养者中，570人的常用角色已满；955名停养者中，302人的常用角色已满。合计872人对应全部老用户45.8%的净减少额。该比例用于定位值得关注的人群，**不是“饱和造成45.8%损失”的因果估计**。
- 共同可核验的153名限时用券玩家，用券由3,362增至6,700，现金由5,317.29降至2,295.41美元。资源消耗与新增现金可以背离；仍需结合期初库存和当期供给解释。
- 持续少养组的跃之星充值减少16,296.11美元，占该组现金减少额的88.8%。最终消费Top10分别按当周实际消耗量排序，用于看各周主要去向，不再按减少额排榜。

## 固定口径：读报告前需要知道什么

**时间与人群。** 趋势期为2026/8/1–11/5，共97个完整日期；11月仅展示1–5日的日均，不与整月总额比较。主体对照为**8/19–25与10/28–11/3**，均为周三至周二的完整7天。不是9月／10月月度比较。老用户按首次可见登录不晚于7/18固定，历史付费分层使用6/24–7/31；较早记录仅用于历史身份、资源余额、角色状态等背景。事件表的账号覆盖不等于登录活跃人数，AU必须有登录证据。

**排除规则。** 排除内部账号、沙盒和水军标签账号；内部号识别纳入单笔获得10,000跃之星的记录，兼顾付费星与免费星字段。识别及新增排除核查在SQL和查询回执中保留，不能只按单一币种识别。

**持续少养。** 2,049名玩家在两周均登录、均有等级／觉醒／天赋操作，后期操作总次数少于前期。次数是操作记录数，不等于养成成功次数，也不代表相同资源成本。活跃日校正用于判断是否仅因登录天数减少。

**角色状态。** A、S分别统计；已有持有证据但没有觉醒记录时按觉醒0处理，其他字段按SQL定义取状态。常用角色取相应窗口前14日上场最多的3名A／S角色。当前满养判断为等级10、觉醒3、天赋6；没有上场记录的人不能直接归入常用角色全满。

**成本与抽数。** 等级目标成本为17,710纪念币＋4,400意志结晶；天赋目标为4,500意志结晶＋35天赋币；合计17,710纪念币＋8,900意志结晶＋35天赋币。抽数预算用限时阅览券＋⌊跃之星余额合计／150⌋衡量；持有胚子和觉醒额外重复角色的需求分开。保底抽数是上限情景，不能当成每名玩家真实抽数或真实现金成本。

**现金与代币。** 现金收入按已确认公式扣钱包免费金额、除汇率并应用订单折扣系数；商品匹配按用户确认的SKU规则，跃之星充值合并为一类，不按支付渠道拆分。免费星字段也可能包含现金充值到账，不能把该字段全部解释为免费供给。付费星消费Top10沿用资源ID3的实际扣减口径；资源预算章节同时考虑星3和星8，两者范围不同。

**第59页Top10。** 固定同一批2,049名持续少养玩家，各周按“扣款原因×商品／项目ID”的当周付费星消耗降序取10项，排除退款回收。前期总消耗899,679星，Top10占82.8%；后期192,285星，Top10占91.8%。缺名称时显示ID，不猜名称。两图独立刻度，柱上为实际星数，不能跨图只比较柱长。现金榜仍为“跃之星充值1项＋其他具体商品Top14”，按减少额排序。

