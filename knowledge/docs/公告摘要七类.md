# 官网公告摘要七类

## type 七类
版本更新、职业平衡、违规行为、官方引导或攻略、新内容预告、其他声明、赛事信息。

## key_content 写法
- 简体中文、150 字内、只从原文提取（不补写推断）。
- 禁模板句（"本文介绍了…"这类一律不用）。
- 禁大段复制原文；按类型组织要点。

## 图片公告降级
- 正文以图片为主、无法提取有效文字时，写「正文以图片为主，无法提取有效文字摘要」，不要硬编。

## 注意事项
- 一篇公告只有一个 type，判断不下时选最接近的主旨而不是多标。
- 保留原文可追溯性：摘要服务于检索与汇总，正文始终以原文为准。
