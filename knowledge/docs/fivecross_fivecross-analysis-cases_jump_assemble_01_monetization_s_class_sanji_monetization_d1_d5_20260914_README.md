# Jump Assemble TC — 香吉士 S 級販售診斷

## 結論

香吉士首五日的主要問題是**進池規模不足**，不是已進池玩家的抽取深度不足。

- 目標池參與率為 **4.4%**，低於白哉的 **10.6%**（-6.2 個百分點）。
- 總抽取 **43,944** 次，為白哉 **86,296** 次的 50.9%；香吉士參與者人均抽取 **24.5** 次，反而高於白哉的 **16.6** 次。
- D1–D5 活躍帳號的全遊戲有效付費營收為 **$63,562**，較白哉 **$120,403** 低 47.2%。此營收是活動期商業背景，不能直接歸因到目標池。
- 各累計付費檔位的目標池參與率都低於白哉；免費檔為 10.0% vs 20.0%，$10–100 檔為 10.0% vs 20.0%，$1,000+ 檔為 60.0% vs 70.0%。
- 香吉士最後快照持有者僅 465 人（D1–D5 活躍帳號的 3.3%），低於白哉 978 人（5.8%）；但香吉士持有者中 3+ 覺醒率為 39.1%，高於白哉 22.7%。這支持已進池者仍有深抽意願，不能將持有者內的覺醒率當成整體轉化率。

## 範圍與口徑

所有池子都使用完整首五日 D1–D5：佩恩（7/15–7/19）、凑（8/12–8/16）、白哉（8/26–8/30）、五條復刻（9/2–9/6）、香吉士（9/9–9/13）。

- 資料源：ThinkingData / Trino `ta.v_event_23`。
- 活躍：`LOGIN_SUCCESS` 去重帳號，排除內部／水軍／可疑 IP 群組。
- 目標池：精確 `active_gacha.gacha_id`；香吉士為 107，白哉為 105。
- 檔位：截至各自 D5 的累計有效付費金額。
- 覺醒：D1–D5 可用 `daily_role_card_snapshot` 的最後一筆，`CARDINALITY(card_awake)`。

### 簡報指標定義

- **去重活躍帳號**：各池 D1–D5 內至少一次 `LOGIN_SUCCESS` 的 `account_id`，窗口內去重並排除內部、水軍與可疑 IP。
- **去重目標池參與者**：去重活躍帳號中，目標 `gacha_id` 的 `active_gacha` 累計 `count > 0` 的 `account_id`，窗口內去重。
- **目標池參與率**：去重目標池參與者 / 去重活躍帳號。簡報 v11 起，第 1、3 頁均採此口徑；不再使用按日人天加總的加權率。
- **總抽取**：目標池 `active_gacha.count` 的總和，單位為抽取次數，不去重。
- **平均抽取次數／去重參與者**：總抽取 / 去重目標池參與者。
- **各付費檔位參與率**：同一累計有效付費檔位內的去重目標池參與者 / 去重活躍帳號；累計有效付費截至各池 D5。
- **持有人與持有率**：D1–D5 最後一筆 `daily_role_card_snapshot` 中存在目標角色的去重活躍帳號；持有率 = 持有人 / 去重活躍帳號。
- **3+ 覺醒率**：覺醒數至少 3 的持有人 / 持有人。
- **跨池樣本**：付費、非水軍，且五個池各自 D1–D5 窗口皆至少登入一次的去重帳號；第 6 頁的全池抽取與全角色 3+ 覺醒均以此為分母。
