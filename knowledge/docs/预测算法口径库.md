# 预测算法口径库（留存拟合/MAU/LTV）

## 留存拟合
- 拟合数据点 index = [2, 3, 7, 14, 30, 90, 180, 360]；拟合值填回原始数据点。
- weibull_fix：weibull 拟合（c + a·exp(−(t/λ)^k)）；如果超过 360 天，增加长期约束：720留 = 360留 × 0.5；1080留 = 720留 × 0.7；1440留 = 1080留 × 0.7；1800留 = 1440留 × 0.7；没有 360 数据点时先拟合取 retention_360。
- exp2_fix：双指数 c + a1·exp(−b1·t) + a2·exp(−b2·t)，bounds [0,1]×5。
- 拼接口径：前 360 日用双指数函数，360 日后长期留存用 weibull。

## MAU 约束
- 如果新增相同或下降，MAU 不应该增加。
- MAU 环比 < 0.7 时 ×random(0.85, 0.9) 平滑；环比 > 1 时 ×random(0.95, 0.98) 平滑。

## LTV 长期约束
- LTV = Σ_d 留存率_d × 留存ARPU_d；留存ARPU = 分日 LTV 增长金额 ÷ 当日留存用户（d=0 时留存用户=注册用户、留存率恒 1）。
- 取数：买量投放KPI（注册锚点 cohort，ad_attr='first'，utc8）改写为分日长表，实测 0..30 天，30 天后由模型外推。
- 留存率：exp2 双指数拟合（同「留存拟合」节，bounds [0,1]）；实测点不足 3 个回退相邻实测点水平外推（保守）。
- 留存ARPU：指数衰减 A·e^(−b·d)+C（A,C≥0）拟合；实测点不足 3 个回退末个有效 ARPU 水平外推（保守）；无任何付费数据则 ARPU=0、LTV=0。
- 长期部分由留存率外推自然收敛（原「按目标值拓展 + weibull 长期约束」的离线上传口径已由本数据驱动口径取代），不与短期留存外推打架。

## 注意事项
- 拟合失败要回退到可解释的保守口径并注明，不能硬报错或静默用错值。
- 这里的参数是口径决策（不是可调超参），改任何系数都要同步文档与回归测试。
