# 概念收集两阶段

## 阶段 1：概念候选提取
- 不做分词、保留原始用语（用户怎么说就怎么收）。
- 候选 1~8 字；宁多勿漏（多收可以后面过滤，漏了就没有）。
- 忽略纯日常用语（问候、闲聊）；输出 JSON 数组。

## 阶段 2：语义聚类归一化
- 输出 canonical_concept（规范概念名）、aliases（原始表达全保留）、concept_type（11 类）、canonical_meaning（规范含义）、sentiment_bias（情感倾向）、filtered_out（噪声剔除名单）。
- 同概念不同语言/不同说法归一组（aliases 不丢原始用语）。

## 注意事项
- 两阶段严格分离：阶段 1 只负责"海提"，不承担归一职责；阶段 2 才有聚类与噪声判定。
- 阶段 2 的 filtered_out 要能追溯被剔掉的原因，方便人工复核（人治可调）。
