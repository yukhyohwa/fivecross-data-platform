# 首屏启动建议（8 条示例）

## 8 条首屏示例（已改写成通用表述，原示例中的 rooc 专指已标注）
1. **KPI**：查产品 KPI 概览——注册/活跃/付费/留存，可按国家、渠道分组（原示例查 rooc 的 KPI，换游戏时改游戏代码）。
2. **日志表**：从元数据库找某日志的表名与字段说明。
3. **调度**：查 DS 调度任务/工作流/实例/日志。
4. **配置**：查 GitLab 上某游戏的配置表（分支 + 表名）。
5. **报表**：从 JoyData 平台快照找报表与 SQL。
6. **数仓**：直接写只读 SQL 查数仓。
7. **导出**：把查询结果导出为 xlsx/csv 文件。
8. **角色事件**：查某角色一段日期内的事件与道具/货币/铜币流水。

## 写法规范
- 每条示例是 (能力key, 标题, 副标题, icon, 完整提示词) 五元组——完整提示词让用户一键发起，不让用户从零组织问题。
- 示例是通用模板，涉及具体游戏（原示例多为 rooc）时按目标游戏改写。

## 注意事项
- 首屏只挂已授权能力；新能力上线时同步补一条示例。
