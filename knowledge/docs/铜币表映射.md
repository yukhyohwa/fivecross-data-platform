# 铜币表映射（moneyflow2 与 moneyflow101）

## 适用游戏
rooc 及其同系游戏（rooc_am / ro_hmt / ro_sea / ro_lna）。

## 铜币表映射（COPPER_MONEY_TABLE）
- rooc → rooc.dwd_moneyflow2_log
- rooc_am → rooc_am.dwd_moneyflow2_log
- ro_hmt / ro_sea / ro_lna → 各自库 dwd_moneyflow101_log

## 差异口径
- rooc/rooc_am 用 moneyflow2；ROO 三区用 moneyflow101。
- operatordetail 是 moneyflow2 独有字段，ROO 三区流水表无此列——SQL 模板用 CAST(NULL AS STRING) 兜底。
- sr_ts：itemflow/moneyflow/铜币流水仅 rooc/rooc_am 有（ods_others_log 全区都有）；按"入库"时间过滤时三区流水表没有 sr_ts、那几段实际上不受过滤（会明确提示）。

## 注意事项
- ro_zxf（自选服）不分范围，事件来自 ro_zxf.ods_ro_log 合集、按 TLog 定义文件解析，不走本映射。
- 事件名铜币表对应 dwd_ 前缀 + _log 后缀（dwd_moneyflow2_log → moneyflow2），拼表名时不要自己发明。
