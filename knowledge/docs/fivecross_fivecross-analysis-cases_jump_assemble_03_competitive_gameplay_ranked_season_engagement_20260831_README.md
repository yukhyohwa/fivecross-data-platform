# JUMP TW 排位赛季参与、再排与 Bot 暴露诊断

## 问题

在 OBT 赛季中，排位目标感是否转弱；Bot 暴露是否会让高投入（当日 >=10 局）玩家减少后续再排。

## 已执行的 Bot 验证

- 范围：2026-07-15 至 2026-08-21 的当日 >=10 局帐号；D+1、D+3 均有完整观察窗。
- 暴露：当天排位对局中 `robot_num > 0` 的对局占比；比较 0% Bot 与 >0% Bot。
- 结果：原始差异很大，但控制日期、段位、局数、胜率后的差距明显缩小，说明大部分表面差异由玩家/对局构成解释。
- 稳健性检验：进一步在同日、段位、局数、胜率、队列人数、等待时长相近的共同 strata 内标准化；0% Bot 的 D+1/D+3 再排为 84.74% / 71.90%，>0% Bot 为 82.68% / 69.47%，差异为 -2.06pp / -2.43pp。
- 覆盖：共同 strata 样本为 26,795 个帐号日，占全部重度帐号日 54.5%。

## 可用结论

Bot 暴露与高投入玩家少再排存在小幅、控制后仍保留的相关性；现有观察数据不足以证明因果，也不足以单独认定 Bot 是赛季末再排下滑的主因。下一步应以随机化 Bot 阈值／匹配策略实验，主看 D+1/D+3 再排率，并以等待时长、胜率、D7 登录为护栏。
