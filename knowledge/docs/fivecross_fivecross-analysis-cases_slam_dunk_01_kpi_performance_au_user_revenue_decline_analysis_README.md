# 灌篮高手全球版AU报告

## Case 文件

- `sql/01_monthly_user_revenue.sql`：月度用户分层、收入、ARPU 与新增留存查询。
- `sql/02_country_comparison.sql`：按国家/地区比较新增、老用户、收入和 ARPU。
- `data/historical/`：生成本报告的历史聚合 CSV。
- `reports/au_user_revenue_decline_report.pdf`：历史报告 PDF。
- `VALIDATION_CHECKLIST.md`：复跑或扩展时间范围时的校验项。

## 数据与口径

数据源为阿里云 `dm_platform.daily_lcx_user_info`，全球版 App ID 为 `63002013`。用户在月度层面拆分为：

- `New`：注册月份等于当前活跃月份。
- `Old_RegL2M`：上月仍活跃、且注册在当月及前两个月的近期获留用户。
- `Old_OTH`：上月仍活跃、但注册早于近两个月的核心老用户。
- `Return`：当月活跃但上月未活跃的用户。

历史报告覆盖 2025-10 至 2026-02 的下降诊断，并以 2025-03 作为部分国家对比基准；重新取数时应按新观察期复核结论，不能将历史结论直接当作当前状态。


仅分析2025.10-2026.02 的用户与收入下降；（已知 2026.03，新用户显著下降节点为2026年3月10日，黑子泰国上线时）。

**结论**：
- 近半年因新用户不足，导致用户规模急剧萎缩，但2026.02新用户规模显著回升
- 虽然引入了 NUU 流量，但留存下来的这批用户在生命周期前两月的转化极不理想。

### 1.2 细分群体人均付费

| :--- | :--- | :--- | :--- | :--- | :--- |
| **2025-01** | ¥22.58 | ¥55.94 | ¥17.24 | ¥1.89 | ¥4.06 |
| **2025-02** | ¥15.62 | ¥35.30 | ¥10.82 | ¥3.14 | ¥3.91 |
| **2025-03** | ¥26.43 | ¥60.89 | **¥17.11** | **¥5.44** | ¥7.74 |

**结论**：
- 2026 年 2 月核心 ARPU 回升到了 **¥52.19**，主要得益于核心老用户的存量爆发，而非新用户转化；
- 在最近 6 个月中，前 2 个月注册获留的用户（L2M）ARPU 长期处于 **¥5-6** 的低水位；
- 而新用户ARPU从2025年3月的¥5.44下降至2026年2月的¥1.80。
