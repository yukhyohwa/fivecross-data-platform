# 卡牌售卖分析校验清单

在对外写结论前逐项确认。任一项不确定时，应在结论中标注“待验证”，而不是补充因果解释。

## 时间与样本

- [ ] 首日使用的是实际开池时间窗；若只能按自然日，明确其局限。
- [ ] 所有角色使用同样长度的窗口（首日或 Day1–Day7）。
- [ ] `hero_id`、`gacha_id`、返还 reason 已由原始日志抽样核对。
- [ ] 黑名单已排除，并记录版本与日期。
- [ ] 福利号未被直接混入常规用户；至少已单列敏感性检查。

## 收入

- [ ] 排除 `SANDBOX_RECEIPT`。
- [ ] 已扣除 `freeamount`，汇率连接到购买日与币种。
- [ ] 收入、付费人数、ARPU、ARPPU 的分母一致。
- [ ] 商品收入与总收入的差异（未映射 SKU、直充、退款等）已解释。

## 返还与抽卡

- [ ] 返还用户按 `hero_add` 的明确 reason 定义；不以“持有角色”判断。
- [ ] 真实抽数与“返还胚子等价 40 抽”分开保存。
- [ ] 抽数分桶基于目标 `gacha_id`，不混入其他卡池。
- [ ] 同时比较每档人数、收入、ARPU 与 ARPPU。

## 资源与养成

- [ ] 期初资源来自开池前最后快照，非活动中快照。
- [ ] 明确限时阅览券、跃之星、意志结晶对应的资源 ID 和字段含义。
- [ ] 正向产出按来源拆分；负向消耗按道具和用途拆分。
- [ ] 若声称“券替代付费”，已核对商城/兑换配置、限购与活动奖励。
- [ ] 同抽数档已比较角色等级、觉醒和（可用时）排位表现。

## 因果表述

- [ ] “相关”与“因果”分开写。
- [ ] 若使用匹配对照，列出了匹配期、特征、样本量和匹配后平衡性。
- [ ] 没有把“非返还组”自动称为“匹配对照组”。
- [ ] 已说明角色强度、同期活动、SKU 调整、自然日差异等混杂因素。
