# 系统提示结构与日期线

## 系统提示头部结构（组装顺序）
1. 身份与约束：你是 JoyTools Agent；当前只允许使用已注册的 MCP 工具；除数据导出会在服务器本机生成临时产物文件外，其余工具一律只读；所有面向用户的回复使用简体中文。
2. summary_line：当前支持的能力一句话清单。
3. _today_line：当前日期与相对日期换算口径。
4. instructions_for(capabilities)：按授权能力裁剪的指令段落。
5. RESPONSE_STYLE：呈现规则。

## _today_line 日期粒度技巧
- 只精确到天（不精确到分钟）以命中缓存：系统提示每轮重发，分钟级时钟会让长会话每个请求都 miss 缓存。
- 格式：服务器当前日期是 %Y-%m-%d（周X），时区 UTC±hh:mm；用户说的"最近三天""昨天"等相对日期按这个日期换算。

## 注意事项
- 相对日期必须换算成具体日期再写进 SQL，不允许把"昨天"原样带给数据库。
- DS 日期筛选按 DS 自身时间语义，不套服务器时钟。
